## Engineering problems observed and resolved

- **E005-001 — Decimal display formatting vs monetary equality:** first new tests yielded 2 failed/78 passed; one expected error message matched wrong wording, another compared `10000.000` and `10000.00` as strings. Corrected error wording and compare Decimal economic value numerically; Mac rerun **80 passed**, later 89 passed after extra tests.
- **E005-002 — Missing upstream market connection:** Eastmoney unadjusted quote request failed via Mac `requests.exceptions.ProxyError` during a three-event real nominal accounting probe. Reused the prior provenance-hashed 2026-10-26 real unadjusted source marks; checks assert PDF SHA/source hash, dates, share count and payout match. Recorded `data_reused_not_fetched_this_run=true`; no fabricated bars or success claims.
- **E005-003 — Floating-point cash representation:** SZ000001 issuer cash was serialized as 0.22799999999999998 from floating-point conversion. Canonicalized to 9-decimal issuer cash precision before `Decimal` accounting; 228 RMB pretax claim per hypothetical 1000 nominal shares verified.
- **E005-004 — Other securities' rights-issue halts:** simple '股票将于...复牌' text does not itself establish start of the preceding halt. Used original-PDF clauses for start/end subscription period plus clearing day and subsequent resumed open, validating each against Qlib exchange calendar and each source PDF SHA. Five valid six-session halts with zero conflicting daily Qlib positive prices.
- **E005-005 — Mac `git pull` network failure:** latest normal GitHub fetch failed with `Empty reply from server`. Avoided overwriting worktree or mislabeling version; connected GitHub file connector supplied exact source into a gitignored mirror for Mac CPU unit/evidence checks.
