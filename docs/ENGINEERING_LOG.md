## 2026-10-26: design and GitHub initialization
- **Q-001 Possible look-ahead:** using close(t)-to-close(t+1) returns as though a close(t) order could be filled. Preventive fix: explicit features through close(t), target next-open(t+1) to following-open(t+2). Automated feature/label tests. Status initially pending execution.
- **Q-002 Model selection leakage:** tuning on future test data or training labels unavailable at a fold boundary. Preventive fix: two-session date separation for labeled observations at validation and test starts; select candidate only on preceding validation data. Boundary assertions and tests. Status initially pending execution.
- **Q-003 Transaction-cost understatement:** switching a position sells old + buys new; net vs gross benchmark unfair. Fix: charge absolute weight change to both model and equal-weight benchmark; test a two-session switch.
- **Q-004 Invalid market claim:** toy data can produce convincing but meaningless Sharpe. Fix: mark synthetic source explicitly in README, CLI manifest and output.
- **Q-005 Dynamic universe / halted asset problem:** cannot safely forward-fill an open price for an untradeable asset. Fix in v0: reject unbalanced panels. Remains **open**: survivorship bias, changing membership, corporate actions, liquidity.
- **Q-006 Platform dependency:** Mac system Python was reported as 3.9.6 (too old for project) and base system lacked numpy/pandas/sklearn/lightgbm/pytest. Fix: use existing Python 3.12 located at ~/.local/bin/python3.12 in a project .venv. Verification pending actual install and test result.

Fix: split into smaller, syntactically isolated GitHub file commits. Verification: targeted GitHub create_file commits for tests, followed by repo inspection.

## 2026-10-26: stage 2 — pinned real-data Qlib + honest baselines

The historical "Real-market experiments not run" entry above describes the *end of stage 1* and is now superseded by this stage-2 log. **This is not a live-trading or positive-alpha result.**

- **Q-010 — Public market-data access failures.** Stooq CSV GET served a JavaScript browser-verification page rather than CSV; Yahoo Chart endpoint returned HTTP 429; a guessed direct Qlib Azure Blob URL returned HTTP 409 (public access disabled). **Resolution:** use the community-maintained [chenditc/investment_data](https://github.com/chenditc/investment_data) release explicitly referenced by Microsoft Qlib docs. Pinned release *2026-10-25* and downloaded both \`qlib_bin.tar.gz\` and matching manifest. No bot checks bypassed.
- **Q-011 — Source integrity and persistence.** Publisher manifest gives archive bytes **569210863**, archive SHA-256 **0a2974da97b4737e503ecddeea8bb3b2179e0e16ea0fb19fa373ff14155bf315**, trade date **2026-10-23**. Ran \`python scripts/verify_qlib_bundle.py ...\` and verified **67,904** archive members: SHA, byte size and disallowed symlinks/traversal. Extracted to *gitignored* \`data/external/qlib_20261025\`. Did **not** commit source binaries/market prices.
- **Q-012 — Qlib macOS spawn failure.** \`python - <<'PY'\` calling \`D.features\` with default Qlib parallel workers repeatedly failed \`FileNotFoundError: .../<stdin>\` inside Python \`multiprocessing.spawn\` on macOS. Stopped the diagnostic process; initialized Qlib with \`kernels=1\` and used an importable \`python -m quant_lab.real_qlib\` module. Verified \`D.features\` for two symbols, and \`Alpha158(... learn_processors=[],infer_processors=[]).fetch(...DK_I)\` with **780 rows × 158 features** for a three-name trial. This is a Qlib launcher/environment issue, not stock-data corruption.
- **Q-013 — Point-in-time and halt filtering.** Parsed \`instruments/csi300.txt\` from the pinned source and compared the *2024-01-02* membership against independent \`D.list_instruments\`: exact match, **300** initial constituents. Selected exactly **12** sorted tickers based only on that inception date, then used historical membership eligibility and global exchange-calendar price shifts. **Root risk:** filtering signal candidates according to tomorrow's missing open is look-ahead bias. **Preventive fix:** abort if otherwise eligible day has no future execution/settlement open; added no-lookahead tests for missing future opening. Real sample: **zero** missing future-tradability entries, **zero** missing adjusted price rows for this limited 12-name sample. This is not an all-market survivorship guarantee.
- **Q-014 — Future settlement at study end.** Fetching only to last decision date makes final two labels unavailable and would wrongly filter based on future information. **Fix:** request exchange-calendar sessions past the study end to settle open(t+1) to open(t+2), while restricting signal decisions to the declared 2024–2025 window.
- **Q-015 — Preprocessor contamination risk.** Default Qlib Alpha158 learn processors may fit transformations on a future range relative to early folds. **Fix:** fetch raw inference features with both infer/learn processors explicitly disabled; Ridge \`SimpleImputer(strategy='median')\` and \`StandardScaler\` are fitted **inside each train fold only**; LightGBM uses native missing handling. Add future perturbation/holdout tests.
- **Q-016 — Pandas fixture fragmentation warnings.** \`tests/test_pit_universe.py\` initially produced **126 PerformanceWarning** messages from repeatedly inserting 140 synthetic columns despite **15 passed**. Replaced loop with a single concatenated dataframe for clean CI output. Awaiting final consolidated test.
- **Q-017 — Real historical experiment completed.** All three models used identical 328 out-of-sample decision days, 10 expanding time folds, 12 names, 158 Alpha158 + 6 custom factor features (for Ridge/LightGBM), 10bps modeled fees. At 10bps, cumulative net: momentum **−22.70%**, Ridge **−27.21%**, LightGBM **−28.60%**. Same-basket equal weight **+13.49%**. OOS RankIC: +0.00054, -0.00481, -0.03602. None show useful positive alpha. See \`docs/REAL_DATA_REPORT.md\` and the machine-readable experiment JSON.
- **Q-018 — Cost sensitivity and uncertainty.** To diagnose high turnover, **reused frozen model predictions** without retraining or optimizing on the held-out period and recalculated fees **0/5/10/20bps**. At 0bps momentum -3.32%, Ridge -1.30%, LightGBM +2.60% vs equal-weight basket +13.61%. 10bps fees exacerbate underperformance. Paired 5-session moving-block bootstrap 1500 draws computed descriptive intervals; these are **not** valid claims of live-market statistical alpha. Full sensitivity archived in JSON.
- **Research blockers before strong conclusions:** corporate-action adjustment as-of correctness, changing/exited stocks beyond 12-symbol frozen cohort, delisting cash settlement, suspensions, price limits, open-auction fill feasibility, slippage/impact, lot-size constraints, robust risk exposures and untouched test periods. All model and source caveats remain in the reports.
